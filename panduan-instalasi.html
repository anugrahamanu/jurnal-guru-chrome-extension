Panduan Pemasangan Ekstensi Chrome

Jurnal Guru Digital & LMS (Khusus Guru & Tenaga Pendidik)

4 Langkah Mudah Pasang Ekstensi (1 Menit)

1
Ekstrak File ZIP

Pastikan Anda sudah mendownload file chrome-extension.zip. Klik kanan file tersebut, lalu pilih Extract All (Ekstrak Semua) hingga menjadi folder biasa.

2
Buka Menu Ekstensi Chrome

Buka browser Google Chrome di laptop Anda, lalu ketik pada kolom alamat web:
chrome://extensions lalu tekan Enter.

3
Nyalakan Mode Pengembang

Lihat di pojok kanan atas layar Chrome, aktifkan sakelar "Mode Pengembang" / "Developer mode" hingga berwarna biru.

4
Muat Folder Ekstensi

Klik tombol "Muat yang belum dibongkar" (Load unpacked) di pojok kiri atas, lalu arahkan dan pilih folder hasil ekstrak tadi (folder chrome-extension). Klik Select Folder.

SELESAI! Ekstensi Jurnal Guru langsung aktif di browser Anda dan sudah otomatis tersambung ke https://gurugenz.my.id tanpa perlu setting apapun lagi!

Cara Menggunakan Ekstensi

Sematkan Ikon (Pin)

Klik ikon Puzzle di kanan atas Chrome, lalu Pin logo Jurnal Guru agar selalu tampil di toolbar.

Bilah Samping (Alt + J)

Tekan tombol Alt + J untuk membuka Jurnal Guru di samping tab saat browsing materi.

Pintasan LMS Cepat

Klik tombol LMS Guru di atas bilah samping untuk langsung masuk ke tugas dan modul kelas.

Buka Layar Penuh

Klik ikon panah kotak di pojok atas kapan saja untuk membuka halaman di tab penuh baru.
